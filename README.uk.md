# OpenZone Research

*[In English](README.md)*

Бали досліджень і дерево технологій для серверів OpenZone, на ядрі OpenZone.

**Стан: будується.** Це наступник `ZP_Research`: правила гри ті самі, код новий і стоїть на
службах ядра. Із сервера ZP_Research нічого не переноситься: цей мод стартує порожнім.

## Що робитиме

- Зразки переробляються на **станціях** за **правилами** адміністратора у предмети даних
  або **носії балів**.
- Носії здаються у **термінал фракції** й поповнюють **пул балів** фракції.
- Пул витрачається на **дерево технологій** фракції: миттєво або проєктом зі строком.
- Фракція -- ядрова: угруповання гравця, інакше його базова фракція. Пул витрачає лідер
  угруповання або власники посади, названої в налаштуваннях.
